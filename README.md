## 📊 Projects

### [SQL Portfolio — E-Commerce Revenue & User Analysis](https://github.com/MillieMeng/sql-portfolio)
Analyzed **100k+ orders** and **27k+ users** in BigQuery using CTEs and window functions to evaluate order status, monthly GMV, cohort retention, and RFM segments. Identified a **25% order non-conversion rate** from cancelled and returned orders; built Champions, Loyal, and At Risk customer segments to support differentiated retention strategies.

`SQL` `BigQuery` `cohort retention` `RFM segmentation` `window functions`

### [Cognitive Control — Automated Behavioral Data Pipeline](https://github.com/MillieMeng/cognitive-control-flanker)
Reproducible R pipeline processing **8,000+ trial-level observations** across congruent and incongruent Flanker conditions. Automated participant-level visualizations with reusable ggplot2 functions; modeled response-time trends with LOESS regression; documented in RMarkdown.

`R` `tidyverse` `ggplot2` `LOESS regression` `RMarkdown`

### [Predictive Modeling — Attachment & Mental Health](https://github.com/MillieMeng/attachment-self-compassion-study)
Multiple regression model (R² = .31) on archival survey data **(N = 473)**. Full assumption testing (normality, homoscedasticity, multicollinearity, outliers) with effect sizes reported in a reproducible RMarkdown analysis.

`R` `multiple regression` `ANOVA` `RMarkdown`
